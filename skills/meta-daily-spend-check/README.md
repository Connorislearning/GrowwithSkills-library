# Meta daily spend check

A five minute morning check that tells you where money is leaking, biggest leak first.

## The problem

Ads Manager shows everything and prioritizes nothing. A buyer running dozens of ad sets can miss the one burning money with zero leads, because it looks like every other row.

## My process

I run the same six checks every morning. Zero results burn. CPA drift. Underdelivery. CPM spikes. Fatigue. True overspend.

Overspend is the one most people get wrong. Meta spends above the daily budget on some days and balances it out across the week. So I check the 7 day total, not yesterday alone. That cuts out false alarms.

Then I rank every flag by dollars at risk. A small ad set with a bad CPA matters less than a big one drifting. The output reads like a Slack message, and if nothing is wrong it says so in one line.

It recommends. It never touches the account on its own.

## Assumptions to confirm

The thresholds (2× target CPA, 50% drift, 70% delivery, 30% CPM, frequency 3) are starting points. Tune them per account.
